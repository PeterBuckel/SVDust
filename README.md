# Spatially Variant Scattering-Based Single-Image Dust Removal

Python implementation of the single-image dust removal method described in the paper
*Spatially variant scattering-based single-image dust removal in agriculture* (Biosystems Engineering, 2025).

## Requirements

```bash
pip install opencv-python numpy scipy
```

## Usage

Put your images into a folder named `Input_folder` next to `main.py` and run:

```bash
python main.py
```
